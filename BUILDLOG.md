## AI Usage Log

I used AI as a helper while building this project. It helped me understand the project structure, plan some of the API routes, and write first drafts of parts of the server code. It was also useful for explaining error messages and suggesting ways to test the widget and submission flow.

The AI was not always correct. Some suggestions did not match the way my database and routes were set up. It also suggested code that looked reasonable but did not handle all validation cases, especially missing fields and invalid requests. I did not copy everything without checking it.

I tested the suggested code by running the project and checking the API requests. When something failed, I read the error, checked the related files, and changed the code myself. I added or changed validation, fixed route and database details, and adjusted the widget code so it worked with this project. I also removed suggestions that were not needed.

Overall, AI helped me work faster and learn unfamiliar parts of the project, but I was responsible for checking the code and deciding what to keep. The final implementation was tested and changed based on the actual behavior of the application.
